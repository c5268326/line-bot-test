# stocks.json 資料格式

網頁(`docs/index.html`)啟動時會讀取同目錄下的 `stocks.json`。
檔案不存在或格式不符時,網頁會靜默退回內建的示範資料,不會出錯。

由 `fetch_stocks.py` 產生,經 GitHub Actions 排程 commit 回 repo。

## 格式

```json
{
  "updated_at": "2026-09-05T14:30:00+08:00",
  "source": "fetch_stocks.py",
  "failures": [],
  "stocks": [
    {
      "id": "2330",
      "name": "台積電",
      "bars": [
        ["2026-08-01", 1050.0, 1070.0, 1040.0, 1060.0, 32145],
        ["2026-08-04", 1060.0, 1080.0, 1055.0, 1075.0, 28000]
      ]
    }
  ]
}
```

## 欄位說明

| 欄位 | 說明 |
| --- | --- |
| `updated_at` | 產生時間,顯示在頁面頂端狀態列。ISO 8601 字串 |
| `source` | 資料來源標記,僅供人閱讀 |
| `failures` | 這次抓取失敗的代號清單,僅供除錯 |
| `stocks[].id` | 股票代號,同時作為網頁內部識別碼 |
| `stocks[].name` | 顯示名稱,可省略 |
| `stocks[].bars` | 日 K 陣列,每筆為 `[日期, 開, 高, 低, 收, 量]` |

## 限制

- 每檔至少要 **30 筆**才會被採用(否則算不出長期均線),建議 250 筆以上
- 日期一律 `YYYY-MM-DD`,由舊到新排序
- 價格為數字而非字串,不要有千分位逗號
